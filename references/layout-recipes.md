# mode1 版式配方 — 原始参考图构图复现指南

本文件是 `references/mode1.md` 的实施补充。每次制作前先查看 `assets/reference-slides/contact-sheet.jpg`，再打开最接近的单页参考图。不能只凭文字描述重画。

## 页眉几何：一块矩形 + 两个下沿镂空

- 页眉主体只有一个连续矩形，颜色沿用对应参考页，不另造颜色。
- 两个等腰梯形从矩形下边缘的内部扣除，缺口显示底层页面背景色；它们是负空间，不是叠加在矩形上方 / 边缘的独立色块。
- 缺口不得向矩形外侧凸出，不添加边框、阴影或分层接缝。
- 章节文字放在右侧缺口露出的页面底色区域；页码、章节信息和回形针的位置按参考图保持。
- 制作前查看 `assets/mode1-header-geometry.svg`；该图只说明几何关系，实际页眉颜色仍以对应原始参考页为准。

## 2. 左右双栏：左大右小

- 左侧约占主体宽度的 40%–48%，右侧约占 40%–50%，不必机械对半。
- 左侧主标题或结论放在主体中部附近，不能贴着页眉。
- 左侧可组合小引导语、大标题 / 结论、扁平色条强调短语。
- 右侧采用 2–4 个编号观点，每项包含小标题和一到两行解释。
- 右侧小标题建议 15–18 pt，正文建议 11–14 pt；左侧核心观点建议 28–36 pt，形成明确的左大右小层级。中文宋体，英文 / 数字 Georgia。
- 右侧观点之间使用 `#D8D2C4` 暖灰**连续实线**，透明度约 30%–45%，线宽 0.5–0.75 pt；不用虚线、点线或深色粗线。
- 左右栏起始高度可以不同，保持参考图的不对称节奏。

## 3. 三行横向并列：有参差但不乱

- 三行从上到下排列，分别使用雾蓝、奶油黄、杏橙。
- 三条矩形使用直角边缘；默认从上到下为雾蓝、奶油黄、杏橙。
- 三行分别设置宽度、x/y 起点与倾角：宽度相差约 2%–6%，水平错位约 0.08–0.22 in；每行独立微倾 `-1.3°` 至 `+1.3°`，混合正负方向，不得三行同向同角度。
- 优先将背景色带与文字整体轻微旋转；文字较多时可只倾斜背景矩形、文字保持水平。行内列关系仍要清楚。
- 三行不要求同起点、同宽度、同高度；不要做成标准表格。
- 每行左侧放情境 / 人群 / 阶段，右侧放具体维度或解释。
- 行内文字基线与列关系仍需清晰；不规则只体现在纸片外形与位置。
- 每行应有标题和足够具体的说明，不得压缩成关键词清单。

## 4. 纸片卡片与便签

### 大面积内容纸片（参考 02）
- 以暖象牙白 `#FCFBEA`、雾蓝 `#B9D6DC`、奶油黄 `#FBF5A9`、深可可棕 `#493729` 为主；单张使用纯色底，不统一套色。
- 横向直角矩形，参考比例约为页面宽度 20%–23%、高度 32%–35%；通常在页面中下部横向排列。
- 每张独立微倾约 `-2°` 至 `+2°`，正负方向混合；宽度、起点、高度和间距略有变化，不做标准 UI 卡片阵列。
- 右上角可放 Georgia Italic 小号编号；正文为 1–3 行短内容，左对齐，留足内边距。
- 贴纸可跨压上沿，但仅在语气适合时使用；不强制加 emoji，不让贴纸遮住正文。
- 不加明显纸纹、撕边、折角、胶带或厚重阴影。

### 小型强调便签（参考 01）
- 细长横向直角矩形，约占页面宽度 18%–22%、高度 5%–8%。
- 奶油黄底、深可可棕字，约 11–14 pt 中文宋体；只放一句短语，尽量单行。
- 可轻微逆时针倾斜约 `-4°` 至 `-6°`，贴近它所强调的标题或导语。
- 阴影可有可无；若使用，只保留极淡的浮起感，不加描边和厚投影。

### 共同规则
- 大纸片负责承载信息，小便签负责强调短句；不要混为同一种组件。
- 手作感来自配色、错位、轻微倾斜和克制的贴纸，不来自脏旧纸纹、撕裂边或复杂材质。
- 便签均使用直角矩形；禁止圆角、胶囊、玻璃拟态和重阴影。
- 不是每页都必须有便签；只有当它能加强信息层级时才加入。

## 5. 星芒与纸感装饰

- 星芒使用自定义不规则自由形状，通常 5–9 个尖角 / 尖瓣，长短、宽窄、方向不等，中心略不对称；不要使用标准五角星、字体星号或同一枚图标重复复制。
- 主星芒建议约 28–52 pt，辅助星芒约 12–20 pt；每页改变尖角轮廓、角度、大小或位置。
- 填充只从奶油黄 `#FBF5A9`、雾蓝 `#B9D6DC`、深可可棕 `#493729` 中选择，不加描边、渐变或发光。
- 回形针、单矩形页眉、两个下沿梯形镂空与页码形成固定识别系统。
- 单页通常一枚主星芒即可；装饰不能压住正文或证据。

## 6. 图片页

- 图片放入直角照片框或纸片底板，外层可加一张轻微错位的衬纸。
- 图片上沿可放小型直角标签，说明截图内容。
- 图片与底板应沿用参考色板；不使用圆角图片容器。
- 优先使用真实项目截图或证据，不使用无关图库图片。

## 7. 空间与页脚

- 主体内容不要全部挤在页面上半部。
- 删除页脚后，要重新调整主体垂直位置与段落间距。
- 页面下方允许自然留白，不默认放置口号或品牌署名。
- 必要的来源与风险提示放在对应内容附近。

## 8. 全局直角限制

所有模式默认使用直角矩形容器。禁止圆角矩形、胶囊标签、圆角卡片和圆角图片框，除非用户明确取消。Mode1 页眉的两个梯形只作为矩形下沿的负空间缺口，不是独立标签容器。

## 9. 交付前检查

- [ ] 参考图背景、字体与色彩关系没有被替换。
- [ ] 页眉是单一矩形，两个等腰梯形在矩形下沿内部形成镂空，露出底层页面背景。
- [ ] 左侧核心观点位置舒展，右侧字号更小。
- [ ] 右侧分隔线足够浅、足够细。
- [ ] 三行信息带略有参差，但阅读顺序清楚。
- [ ] 纸片卡片不是统一等宽等角度的 UI 卡片。
- [ ] 星芒为不规则自定义尖瓣形，大小、轮廓、颜色和角度不机械重复。
- [ ] 右栏分割线为浅色连续实线，而非虚线 / 点线。
- [ ] 三行色带的宽度、起点和正负倾角各自变化。
- [ ] 图片有纸片 / 便签承载。
- [ ] 底部没有无意义页脚。
- [ ] 所有容器遵守直角规则。
