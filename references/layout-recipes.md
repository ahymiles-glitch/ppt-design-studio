# mode1 版式配方 — 参考图构图复现指南

本文件是 `references/mode1.md` 的实施补充。参考图的背景、色彩和字体为固定设计系统；本文件只帮助根据内容选择构图，不意味着可以自由替换视觉体系。

## 1. 内容关系与构图选择

| 内容关系 | 优先构图 | 参考图式处理 | 避免 |
|---|---|---|---|
| 主题 + 目录 | 左侧大标题，右侧编号目录 | 左侧标题有足够呼吸空间，右侧用浅细线分组 | 整页项目符号列表 |
| 核心观点 + 解释 | 左侧大结论，右侧小标题与解释 | 左侧核心观点落在内容区中部；右侧分割线浅 | 左右等宽、文字挤在页眉下方 |
| 多种选择 / 职业路径 | 3–4 张纸片便签 | 不同大小、轻微错位，颜色取自参考色板 | 四张完全相同的圆角卡片 |
| 三类情境对比 | 从上到下三条横向信息带 | 三行颜色不同，位置略有参差，行内结构清楚 | 完全齐平、厚网格的表格 |
| 定义 / 原则 | 左侧大观点，右侧三个编号问题 | “做什么 / 怎么做 / 如何推进”一类层次 | 大段解释文字 |
| 流程 / 工作流 | 纵向编号步骤或错落纸片 | 保留方向感，避免装饰箭头泛滥 | 到处都是无说明箭头 |
| 证据 / 指标 | 结论 + 一个主要证据对象 | 截图或图表嵌入直角纸片底板 | 没有来源的装饰性信息图 |
| 结尾 | 一句记忆点 + 一到两个行动 | 参考图的纯色主体背景与页眉系统 | 只有“谢谢”两个字 |

## 2. 左右双栏：左大右小

- 左侧约占主体宽度的 40%–48%，右侧约占 40%–50%，不必机械对半。
- 左侧主标题或结论放在主体中部偏下的舒展位置，避免贴近页眉。
- 左侧可组合：小型引导语 → 大标题 / 结论 → 扁平色条强调短语。
- 右侧采用 2–4 个编号观点，每个观点包含小标题和一到两行解释。
- 右侧小标题比正文大一档，正文比左侧核心观点小一到两档。
- 观点之间用暖灰色、低透明度、细线分隔；线条不要比文字更醒目。
- 左右两栏的起始高度可以不同，保持参考图的不对称节奏。

## 3. 三行横向并列：轻微参差

- 三行从上到下排列，使用参考图的雾蓝、奶油黄、杏橙等颜色。
- 每条信息带使用直角矩形；可以有轻微的 x/y 偏移、宽度差异和小角度旋转。
- 允许行与行之间不完全对齐，但不要让行内文字倾斜或影响阅读。
- 每行左侧先放情境 / 人群 / 阶段，右侧放 2–3 个解释维度。
- 行内可以采用左侧标签 + 两列说明，或左侧情境 + 右侧三栏。
- 保持中等密度：标题明确，解释具体，不把内容压缩成关键词清单。

## 4. 便签与纸片

- 便签必须为直角矩形。
- 便签之间可轻微错位、不同尺寸、轻微旋转；不要所有卡片使用同一角度。
- 可将照片、界面截图或小图放入便签，外侧留出纸张边距。
- 图片标签可以像小纸条一样贴在图片上沿，但保持简洁。
- 不使用圆角、胶囊、厚重投影或玻璃拟态。
- 便签数量根据内容决定，通常 3–4 张足够；不要把整页做成密集便利贴墙。

## 5. 星芒与纸感装饰

- 星芒可用四角、五角、八角或相近形态；大小和旋转角度可以变化。
- 每页通常一枚主星芒；需要时可加一个很小的辅助符号。
- 回形针、顶部标签和页码形成固定识别系统。
- 不要复制同一枚星星到每页相同坐标；也不要随机撒满页面。
- 装饰不能压住标题、解释或证据对象。

## 6. 内容密度与页面下方

- 一页通常包含一个主标题、一个主要构图、3–5 个有意义的信息单元。
- 不要为了“极简”只留一句话和大量空白；也不要把页面塞满。
- 去掉页脚后，要重新安排主体垂直位置和段落间距。
- 核心观点不应全部挤在上半页；可将主体放在内容区中部。
- 页面底部允许保留自然留白，不要为了填空添加口号或装饰性页脚。
- 必要的来源与限定条件放在相关图表或文字附近，而不是固定贴在最底部。

## 7. 全局直角限制

所有模式默认使用直角矩形，包括文本框、信息框、卡片、便签、图片底板、色带和容器。禁止圆角矩形、胶囊标签和圆角图片容器，除非用户明确取消此限制。

## 8. 交付前快速检查

- [ ] 背景、字体和配色仍属于参考图固定系统。
- [ ] 左右栏主次清楚，左侧核心观点位置舒展。
- [ ] 右侧分割线细且浅。
- [ ] 三行信息带略有参差，但行内可读。
- [ ] 便签有自然错位，不是统一的 UI 卡片。
- [ ] 星芒大小或形状有变化，不机械重复。
- [ ] 页面下方没有无意义页脚。
- [ ] 信息密度适中，且所有容器为直角。
