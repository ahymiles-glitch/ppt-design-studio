# mode1 版式配方 — 原始参考图构图复现指南

本文件是 `references/mode1.md` 的实施补充。每次制作前先查看 `assets/reference-slides/contact-sheet.jpg`，再打开最接近的单页参考图。不能只凭文字描述重画。

## 1. 参考图与对应构图

| 参考页 | 内容关系 | 必须吸收的构图特征 |
|---|---|---|
| 01-cover-and-agenda | 封面 + 目录 | 雾蓝主体、深棕顶栏、左侧大标题、右侧编号目录、星芒 |
| 02-internship-pathway | 多路径 / 分类 | 杏橙背景、下半部 4 张错落纸片、不同色块与轻微叠放 |
| 04-role-definition | 左观点 + 右解释 | 左侧大观点位于中部、橙色强调条、右侧 3 个编号说明、极浅细线 |
| 06-three-scenario-comparison | 三行横向对比 | 三种浅色信息带、不同宽度与位置、左情境右维度 |
| 07-closing-principle | 结尾观点 + 行动 | 杏橙主体、左侧两行大字、右侧 2 个观点、星芒与浅细线 |

## 2. 左右双栏：左大右小

- 左侧约占主体宽度的 40%–48%，右侧约占 40%–50%，不必机械对半。
- 左侧主标题或结论放在主体中部附近，不能贴着页眉。
- 左侧可组合小引导语、大标题 / 结论、扁平色条强调短语。
- 右侧采用 2–4 个编号观点，每项包含小标题和一到两行解释。
- 右侧小标题比正文大一档；右侧正文比左侧核心观点小一到两档。
- 右侧观点之间使用 `#D8D2C4` 暖灰细线，透明度约 30%–45%，线宽 0.5–0.75 pt。
- 左右栏起始高度可以不同，保持参考图的不对称节奏。

## 3. 三行横向并列：有参差但不乱

- 三行从上到下排列，分别使用雾蓝、奶油黄、杏橙。
- 三条矩形使用直角边缘；允许不同宽度、轻微 x/y 偏移和极小角度变化。
- 三行不要求同起点、同宽度、同高度；不要做成标准表格。
- 每行左侧放情境 / 人群 / 阶段，右侧放具体维度或解释。
- 行内文字基线与列关系仍需清晰；不规则只体现在纸片外形与位置。
- 每行应有标题和足够具体的说明，不得压缩成关键词清单。

## 4. 纸片卡片与便签

- 参考图中的路径页使用 4 张纸片卡片；尺寸、角度、位置和颜色可以变化。
- 允许轻微重叠、错位和纸张衬底，但文字仍须易读。
- 表情贴纸只在内容语气合适时少量使用；不是每页必备，也不能一概禁用。
- 便签可用于标题、图片说明、结论或风险提示。
- 便签与卡片均使用直角矩形，不用圆角、胶囊、厚重投影。

## 5. 星芒与纸感装饰

- 星芒可以使用四角、五角、六角、八角或相近形态。
- 每页的大小、角度、形状和位置可以变化；不要机械复制。
- 回形针、顶部标签与页码形成固定识别系统。
- 单页通常一枚主星芒即可；装饰不能压住正文或证据。

## 6. 图片页

- 图片放入直角照片框或纸片底板，外层可加一张轻微错位的衬纸。
- 图片上沿可放小型直角标签，说明截图内容。
- 图片与底板应沿用参考色板；不使用圆角图片容器。
- 优先使用真实项目截图或证据，不使用无关图库图片。

## 7. 空间与页脚

- 主体内容不要全部挤在页面上半部。
- 删除页脚后，要重新调整主体垂直位置与段落间距。
- 页面下方允许自然留白，不默认放置口号或品牌署名。
- 必要的来源与风险提示放在对应内容附近。

## 8. 全局直角限制

所有模式默认使用直角矩形容器。禁止圆角矩形、胶囊标签、圆角卡片和圆角图片框，除非用户明确取消。Mode1 的文件夹标签可以使用梯形 / 多边形轮廓。

## 9. 交付前检查

- [ ] 参考图背景、字体与色彩关系没有被替换。
- [ ] 左侧核心观点位置舒展，右侧字号更小。
- [ ] 右侧分隔线足够浅、足够细。
- [ ] 三行信息带略有参差，但阅读顺序清楚。
- [ ] 纸片卡片不是统一等宽等角度的 UI 卡片。
- [ ] 星芒大小与形状不机械重复。
- [ ] 图片有纸片 / 便签承载。
- [ ] 底部没有无意义页脚。
- [ ] 所有容器遵守直角规则。
