# Mode1 参考图视觉分析与审美原则

## 为什么参考图观感好

### 1. 背景本身就是视觉识别系统
参考图不是简单地把文字放在彩色背景上。奶油白纸张边缘、深棕顶部横条、凸起的文件夹标签、页码与回形针构成固定框架；杏橙、雾蓝和奶油黄的主体色块在不同页面之间轮换。观众会把这些页面识别为同一本小册子。

### 2. 字体让页面有编辑感
中文标题的宋体系 / 衬线气质提供视觉个性，正文与辅助文字保持克制。字号差异比大量图标更有效。字体组合应固定，不应每次重新挑选“更现代”的字体。

### 3. 主次分明，但不刻板
左右结构中，左边用较大的标题或结论建立第一视觉焦点，右边用较小的标题和解释补充信息。左右不一定等宽，左侧核心观点也不必紧贴页眉。浅细分隔线让右侧信息有秩序，却不会形成沉重表格感。

### 4. 版式表达内容关系
- 路径分类适合使用错落便签；
- 角色定义适合“大观点 + 右侧三个问题”；
- 不同起点的比较适合三条纵向堆叠的横向信息带；
- 产品体验或证据适合将截图放入纸片、便签或直角底板。
  
版式随内容关系变化，才不会像复制粘贴的模板。

### 5. 轻微不规则让画面有生命力
参考图中的纸片并非全部齐平；三行信息带也可以略有参差。星芒的大小、形状与角度不完全相同。它们制造轻松、俏皮的节奏，但主体文字仍保持清楚。

### 6. 留白与信息密度之间有张力
参考图不会把每个角落填满，也不会把内容削减到空洞。大标题负责抓住注意力，右侧小字和行内说明提供足够信息。去掉页脚后应重新调整主体位置，而不是只留下一个空洞的底部。

### 7. 纸感装饰有明确角色
便签、文件夹标签、回形针、星芒和照片底板共同形成纸质手记的联想。它们不应变成厚重阴影、圆角 SaaS 卡片或随机贴纸。

## Mode1 必须保留的设计约束

- 原始参考图是固定模板，不是可随意改造的灵感板。
- 背景系统、参考色板和字体风格未经用户允许不得替换。
- 左右结构遵循左大右小，左侧核心观点放在舒展的中部区域。
- 右侧观点之间的横线浅而细。
- 三行并列矩形可轻微错位、倾斜，不要求完全齐平。
- 便签可作为文本框的一种选择，并可整合图片。
- 星芒大小、形状和角度应有自然变化。
- 不默认添加底部页脚；底部可以留白。
- 信息密度应张弛有度。
- 所有模式均遵守直角容器限制，除非用户明确取消。

## 应避免的误读

- 只提取配色，却换掉参考图的背景结构和字体。
- 把“俏皮”误解成表情贴纸、卡通插画或大量随机装饰。
- 把“不规则”误解成文字也歪斜、对齐混乱。
- 把“留白”误解成删除大部分内容。
- 把“现代化”误解成圆角卡片、胶囊标签、渐变和玻璃拟态。
- 把每页统一成同一套左右栏或同一组等宽卡片。

## 核心原则

**固定参考图的视觉语法，让构图根据内容变化；保持轻微不规则，但让信息关系始终清楚。**
