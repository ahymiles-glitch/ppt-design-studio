# 参考 PPT 的视觉分析

## 为什么观感好

### 1. 有一套可识别的页面框架
重复出现的顶部色带、页码、章节标签和回形针，让不同页面像同一本刊物中的不同跨页。观众很快学会这套视觉语法，后续页面不必反复解释自己的身份。

### 2. 配色温暖，但并不软弱
杏橙、雾蓝、暖象牙白、奶油黄和深可可棕形成柔和但清晰的对比。它不像高饱和商务色那样有压迫感。不同页面改变主导色，因此重复中仍有变化。

### 3. 字体层级承担大部分视觉工作
大号中文衬线标题提供个性和情绪重量，小号、清晰的正文负责解释信息。标题的字号和位置已经建立阅读顺序，因此页面不需要堆叠很多图标或特效。

### 4. 版式表达内容关系
- 实习路径页使用纸片卡片，因为它在分类选择；
- 角色定义页使用“大观点 + 三个问题”，因为它在解释一个概念；
- AI 实习准备页使用横向色带，因为它在比较不同起点。

内容关系发生变化，版式也随之变化。这是它避免模板感的关键。

### 5. 重复与变化保持平衡
页眉系统、配色、字体和小装饰持续重复；主体内容的构图则根据主题变化。它既有整体识别度，又不会让每一页都像复制粘贴。

### 6. 有纸张般的触感
标签页、回形针、便签、纸片和轻微叠放，让数字页面带有真实文具的联想。它因此更像一本经过排版的手记，而不是软件默认主题。

### 7. 尊重观众的注意力
大多数页面只有一个大观点和少量结构化信息。观众即使不逐字阅读，也能很快理解这页要表达什么。

## 应该提炼，而不是照搬的部分

- 路径页上的笑脸贴纸是创作者针对内容选择的装饰，不是核心视觉规则。
- 回形针和星芒是可重复的母题，不要求每页都同时出现。
- 如果演示文稿很短，或页眉已经挤压正文，应简化顶部标签结构。
- 换成其他主题时，应保留视觉语法，但重做内容结构与案例。
- 视觉极简不能成为删掉关键限定条件、数据单位、来源或风险提示的理由。

## 可迁移的核心原则

**先建立一套小而统一的视觉系统，再让每一页选择最能解释当前观点的构图。**

这比机械复制原稿的颜色、卡片或装饰更有价值。
