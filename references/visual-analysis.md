# Mode1 参考图视觉分析与审美原则

## 参考图是什么

原始参考是一份七页的「产品实习与求职分享」演示文稿。本仓库当前保存了其中五页截图：封面与目录、实习路径卡片、角色定义、三类情境对比、结尾原则。它们共同定义了 Mode1 的背景、配色、字体、布局和装饰系统。

## 为什么它有辨识度

### 1. 背景不是单一色块，而是纸张 + 页眉系统
页面有暖纸色外围、彩色主体、顶部横带、凸起的文件夹标签、页码与回形针。页面主色会在杏橙、雾蓝、暖象牙白之间变化，但框架持续重复。

### 2. 配色温暖，且每种颜色都有角色
杏橙提供视觉能量，雾蓝提供冷静对照，奶油黄承载便签和强调，深可可棕负责标题与文字。它不是把粉彩色平均分配到每页，而是用一种主色统领页面。

### 3. 字体组合稳定
中文以宋体的编辑感为主，英文与数字使用 Georgia 的衬线气质。字号差异建立主次，不需要额外混入现代无衬线字体。

### 4. 版式由信息关系决定
- 封面：左侧大标题 + 右侧编号目录；
- 路径：杏橙背景 + 4 张错落纸片；
- 定义：左侧大观点 + 右侧三个编号问题；
- 对比：从上到下三条不同颜色、略有参差的信息带；
- 结尾：左侧两行记忆点 + 右侧两个行动 / 原则模块。

### 5. 俏皮来自轻微不规则：星芒与纸片
参考图中的星星不是常规五角星图标，而是像手工剪出的不规则星芒：尖瓣数量不完全一致，长短、宽窄、角度和方向各异，中心也不追求严格对称。封面与结尾的星芒更轻盈、放射感更强；角色定义页的雾蓝星芒更短、更钝、更像不规则闪光；路径页可以使用小而深色的简化星芒。

星芒应使用自定义自由形状，而不是字体星号或系统图标。建议主星芒约 28–52 pt，填充使用奶油黄、雾蓝或深可可棕；不加描边、渐变、发光或厚重阴影。每页至少改变轮廓、尖角长短、旋转角度或位置中的两项，不能只换颜色。

纸片和色带也不是标准 UI 卡片。它们可以轻微错位、宽度不同、边缘不齐，并带有小幅度正负倾角；但不规则只服务于纸张的生命力，不得破坏阅读顺序。

### 便签纸有两种，不要混为一谈

**参考 02 的大面积内容纸片**：四张横向矩形纸片分别使用暖象牙白、雾蓝、奶油黄和深可可棕。它们在页面中下部形成一组连续内容路径，尺寸相近但不完全相同，位置和倾斜略有变化。编号通常位于右上角，使用小号 Georgia Italic；正文是少量左对齐的短句，放在纸片中下部。表情贴纸压在部分纸片的上沿，形成前后层次，但这是特定内容的装饰，不是通用模板。

**参考 01 的小型强调便签**：一条细长的奶油黄色直角纸条，贴近左侧导语，略微逆时针倾斜，内部只放一行深可可棕短句。它像编辑批注或重点标记，不负责承载完整信息模块；阴影非常轻，甚至可以省略。

这两种便签的比例和功能不同：大纸片承载 1–3 行信息，小纸条只强调一句话。不要把小纸条放大成卡片，也不要把大纸片缩成标题标签。

**纸感的边界**：原始参考图没有明显的撕纸边、卷边、折角、胶带、图钉、纸纤维噪点或厚重阴影。其手作感来自纯色纸片、轻微错位、独立倾斜和少量贴纸；不应擅自增加复杂的写实材质。

### 6. 右侧分隔线必须克制
参考图右侧观点之间的分隔线是连续的浅色实线，不是虚线、点线或短划线。它只是辅助分组，不是表格边框。浅色页面使用暖灰 `#D8D2C4`，透明度约 30%–45%，线宽约 0.5–0.75 pt；彩色背景上可使用更浅的暖象牙色并降低不透明度。线段长度跟随右侧文字栏，不要贯穿整页；线条不能比文字更醒目。

### 7. 字体、字号与颜色建立清楚层级
中文统一使用宋体，英文与数字统一使用 Georgia；不混入微软雅黑、思源黑体、Aptos、Arial 等无衬线字体。封面主标题约 34–42 pt，普通页左侧核心观点约 28–36 pt，右侧小标题约 15–18 pt，右侧正文约 11–14 pt，三行色带行标题约 13–16 pt、说明约 10.5–12.5 pt，页码 / 元信息约 8–10 pt。上述字号是 16:9 制作标尺，属于基于截图比例的估算，不宣称是原文件精确字号。

主标题和核心观点使用深可可棕 `#493729`，右侧解释使用柔和棕 `#6A584A`，英文眉题、编号和元信息使用更浅的棕灰 `#8A7968`；深棕底色上的文字使用暖象牙白 `#FCFBEA`。强调短语使用杏橙 `#F7A26B` 或奶油黄 `#FBF5A9` 的扁平色条。避免纯黑和荧光色。

### 8. 三行信息带的参差关系
参考 06 的三行色带默认依次使用雾蓝、奶油黄、杏橙。三条矩形并非同一模板的机械复制：宽度可相差约 2%–6%，水平起点错开约 0.08–0.22 in，每行独立使用 `-1.3°` 至 `+1.3°` 的轻微倾角，正负方向混合，不要三行同向平行。倾斜应轻到不影响文字阅读；文字多时可以只倾斜背景矩形，保留文字水平。

### 9. 留白与信息密度保持平衡
左侧核心观点提供第一视觉焦点，右侧小字和信息带提供细节。页面不需要固定底部页脚；底部可以自然留白，但不能把内容削减到空洞。

### 8. 图片应像纸张的一部分
项目截图可以放在直角纸片 / 照片底板中，外层增加轻微错位的衬纸，上沿配小标签。这样图片看起来属于同一本手记，而不是临时插入的网页截图。

## 不应出现的误读

- 只提取颜色，却更换背景系统和字体；
- 将 Mode1 简化成每页相同的圆角卡片；
- 把“不规则”误解为文字对齐混乱；
- 把“俏皮”误解为每页都贴表情；
- 把“留白”误解为删除大量内容；
- 用深色粗线、渐变、发光、玻璃拟态或圆角容器替代原始纸感。

## 核心原则

**以原始参考页作为视觉事实来源；让每页按内容选择构图，但始终保留相同的背景、字体、配色和纸张语法。**
