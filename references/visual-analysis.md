# Mode1 参考图视觉分析与审美原则

## 参考图是什么

原始参考是一份七页的「产品实习与求职分享」演示文稿。本仓库当前保存了其中五页截图：封面与目录、实习路径卡片、角色定义、三类情境对比、结尾原则。它们共同定义了 Mode1 的背景、配色、字体、布局和装饰系统。

## 为什么它有辨识度

### 1. 背景不是单一色块，而是纸张 + 页眉系统
页面有暖纸色外围、彩色主体、顶部横带、凸起的文件夹标签、页码与回形针。页面主色会在杏橙、雾蓝、暖象牙白之间变化，但框架持续重复。

### 2. 配色温暖，且每种颜色都有角色
杏橙提供视觉能量，雾蓝提供冷静对照，奶油黄承载便签和强调，深可可棕负责标题与文字。它不是把粉彩色平均分配到每页，而是用一种主色统领页面。

### 3. 字体组合稳定
中文以宋体的编辑感为主，英文与数字使用 Georgia 的衬线气质。字号差异建立主次，不需要额外混入现代无衬线字体。

### 4. 版式由信息关系决定
- 封面：左侧大标题 + 右侧编号目录；
- 路径：杏橙背景 + 4 张错落纸片；
- 定义：左侧大观点 + 右侧三个编号问题；
- 对比：从上到下三条不同颜色、略有参差的信息带；
- 结尾：左侧两行记忆点 + 右侧两个行动 / 原则模块。

### 5. 俏皮来自轻微不规则
卡片不要求绝对齐平，纸片可以轻微错位或倾斜，星芒大小与形状也不完全相同。它们让页面有生命力，但文字本身仍保持清楚的阅读秩序。

### 6. 右侧分隔线必须克制
参考图中的线条只是辅助分组，不是表格边框。使用暖灰色、细线与低透明度，不能让线条比文字更醒目。

### 7. 留白与信息密度保持平衡
左侧核心观点提供第一视觉焦点，右侧小字和信息带提供细节。页面不需要固定底部页脚；底部可以自然留白，但不能把内容削减到空洞。

### 8. 图片应像纸张的一部分
项目截图可以放在直角纸片 / 照片底板中，外层增加轻微错位的衬纸，上沿配小标签。这样图片看起来属于同一本手记，而不是临时插入的网页截图。

## 不应出现的误读

- 只提取颜色，却更换背景系统和字体；
- 将 Mode1 简化成每页相同的圆角卡片；
- 把“不规则”误解为文字对齐混乱；
- 把“俏皮”误解为每页都贴表情；
- 把“留白”误解为删除大量内容；
- 用深色粗线、渐变、发光、玻璃拟态或圆角容器替代原始纸感。

## 核心原则

**以原始参考页作为视觉事实来源；让每页按内容选择构图，但始终保留相同的背景、字体、配色和纸张语法。**
