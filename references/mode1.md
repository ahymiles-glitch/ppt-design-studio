# mode1 — 参考图锁定式编辑纸感 / 职业手记

## 0. 视觉基准：原始参考图优先

Mode1 的视觉基准是原始「产品实习与求职分享」参考页，而不是泛化的“温暖杂志风”。仓库中的 `assets/reference-slides/` 保存了五张原始参考页裁切图（01、02、04、06、07）及总览图。

- 用户没有明确要求更换时，背景、色彩、字体、页眉、文字分布和装饰语言不得擅自改变。
- 新项目可以改变文字内容、图片内容与页面顺序，但必须保留参考图的视觉语法。
- 参考图负责决定“看起来怎样”；项目资料负责决定“讲什么”。不要照搬参考图的原文或个人经历。
- 其他项目样稿（包括 SHEEN 八页示例）只是 Mode1 的应用案例，不得反过来覆盖原始参考图。
- 现有参考素材只覆盖原始七页参考文稿中的五页，不得臆造缺失页的细节。

## 1. 整体气质

把演示文稿做成一本轻松、有趣、带有纸张触感的编辑式小册子：像经过排版的职业手记、个人作品集或杂志跨页，而不是僵硬的企业模板。

关键词：
- 温暖、低饱和、轻松、俏皮；
- 有手作感，但不幼稚；
- 不对称，但有隐形网格；
- 结构清楚，但不刻板；
- 文字密度张弛有度，不空洞，也不拥挤。

## 2. 背景与色彩：严格沿用参考图

### 2.1 页面背景系统

- 画布默认 16:9。
- 外围可保留暖纸色边界；页面主体在暖象牙白、杏橙、雾蓝等参考色之间切换。
- 顶部反复出现窄横带 / 深棕色横条；横带颜色可按页面主色变化，不要求每页完全相同。
- 顶部横带上方或下方可有一到两个凸起的文件夹标签页，使用参考图的梯形 / 多边形边缘。
- 左上角放小页码；右上角放年份或章节信息，并可配细线回形针。
- 背景应是干净的纯色纸面，不使用渐变、玻璃拟态、噪点纹理或科技风网格。

### 2.2 固定色板

色值按原始参考截图统一采样，作为制作时的固定参考：

| 角色 | 名称 | 色值 | 使用方式 |
|---|---|---|---|
| 主背景 | 暖象牙白 | `#FCFBEA` | 纸张底色、浅色内容页 |
| 强调色 A | 杏橙色 | `#F7A26B` | 大面积主体色、章节横带、强调条 |
| 强调色 B | 雾蓝色 | `#B9D6DC` | 主体色、信息带、次级纸片 |
| 主文字 | 深可可棕 | `#493729` | 标题、正文、深色顶部横带 |
| 强调色 C | 奶油黄 | `#FBF5A9` | 便签、重点短语、小面积强调 |
| 强调色 D | 浅桃色 | `#FBD1B8` | 纸片叠层与柔和辅助强调 |
| 分隔线 | 暖灰色 | `#D8D2C4` | 低对比度细线与弱边界 |

规则：
- 单页通常采用一种主背景色、一种辅助色和深可可棕文字。
- 不要每页把所有颜色平均铺开；颜色必须表达分组、章节或重点。
- 正文优先使用深可可棕，不使用纯黑制造生硬对比。
- 避免荧光色、金属色、强渐变、发光、厚重阴影和高饱和商务蓝。
- 允许颜色块大面积出现；参考图本身就使用杏橙或雾蓝作为整页主体色。

## 3. 字体：锁定参考图，不得擅自替换

Mode1 的字体不是可自由挑选的变量。

- **中文字体：宋体。**
- **英文与数字字体：Georgia。**
- 当前最终应用样稿的字体检查结果同样为宋体 + Georgia；继续沿用这一组合，保持全篇一致。
- 中文标题、正文、标签、页码和说明统一保持参考图的宋体气质，不要另加一套无衬线中文字体。
- 英文标题、拉丁字母、数字编号沿用 Georgia；必要时使用 Georgia Italic。
- 禁止未经允许替换为微软雅黑、思源黑体、Noto Sans、Aptos、Arial 或其他不同风格字体。
- 如果目标设备缺少宋体或 Georgia，先说明字体替换风险；未经用户允许不得静默换字体。
- 如果用户提供原始 PPTX 或字体文件，以其实际字体设置为准。

16:9 页面字号参考（这是根据原始截图比例制定的制作标尺，不代表截图能反推出原文件的精确字号）：

| 文字角色 | 建议字号 | 字体与字重 | 颜色 |
|---|---:|---|---|
| 封面主标题 | 34–42 pt | 中文宋体，常规 / 中等字重 | 深可可棕 `#493729` |
| 普通页左侧核心观点 | 28–36 pt | 中文宋体，常规字重 | 深可可棕 `#493729` |
| 普通页主标题 | 26–34 pt | 中文宋体，常规 / 中等字重 | 深可可棕 `#493729` |
| 右侧分区标题 | 15–18 pt | 中文宋体，中等字重 | 深可可棕 `#493729` |
| 右侧解释正文 | 11–14 pt | 中文宋体，常规字重 | 柔和棕 `#6A584A` |
| 三行色带中的行标题 | 13–16 pt | 中文宋体，中等字重 | 深可可棕 `#493729`；深棕色带上用暖象牙白 `#FCFBEA` |
| 三行色带中的说明 | 10.5–12.5 pt | 中文宋体，常规字重 | 深可可棕 `#493729`；深棕色带上用暖象牙白 `#FCFBEA` |
| 英文小标题 / 章节眉题 | 8–10 pt | Georgia Italic | 柔和棕灰 `#8A7968` |
| 数字编号 / 页码 / 元信息 | 8–10 pt | Georgia；编号可用 Italic | 柔和棕灰 `#8A7968` |

字号层级规则：
- 左侧核心观点必须明显大于右侧解释；右侧小标题大于右侧正文一档。
- 正文通常保持 11–14 pt；只有脚注、来源等次要信息才可略小，不得为了塞内容把整页正文压成小字。
- 文字颜色不要全都使用同一个深色：主观点用 `#493729`，解释文字用 `#6A584A`，页码与元信息用 `#8A7968`。
- 强调词优先用深可可棕字配杏橙 `#F7A26B` 或奶油黄 `#FBF5A9` 的扁平底条；不要用荧光色、描边字或发光字。
- 深可可棕底色上的文字使用暖象牙白 `#FCFBEA`，避免纯白造成过硬反差。
- 不使用纯黑 `#000000` 作为常规标题或正文颜色。

## 4. 页眉、标签、回形针与星芒

### 4.1 固定页眉系统

持续沿用：
- 左上角页码（如 `01 / 07`）；
- 顶部窄色带或深可可棕横条；
- 一到两个凸起的文件夹标签；
- 右上角年份 / 章节信息；
- 右上角细线回形针。

页眉系统是识别整套 Mode1 的关键。位置与比例尽量稳定，标签颜色可变化。标签可采用梯形 / 多边形轮廓，不得替换为圆角胶囊。

### 4.2 星芒：每页有变化，不机械复制

- 星芒是参考图的核心装饰母题之一。它不是普通的标准五角星图标，也不是字体里的星号字符，而是带有手工切纸感的**不规则星芒 / 怪形闪光符号**。
- 优先用可编辑的自定义自由形状绘制：通常为 5–9 个尖角或放射尖瓣，尖角的长度、宽度、夹角和方向不相等；长尖角与短尖角交替，中心略有偏移，轮廓有轻微不对称，但整体仍然稳定、干净。
- 不要把所有尖角做成等长、等角度的规整太阳图标；也不要做成毛刺过多、像爆炸贴纸的锯齿团。
- 每页只需一枚主星芒，必要时加一枚更小的辅助星芒。主星芒建议约 28–52 pt，辅助星芒约 12–20 pt；尺寸随版面变化，不要每页复制同一比例。
- 星芒的填充色从参考色板中选择：奶油黄 `#FBF5A9`、雾蓝 `#B9D6DC`、深可可棕 `#493729`；颜色应与当页主背景形成柔和对比，不另造荧光色。
- 星芒使用纯色填充，不加描边、渐变、发光或厚重阴影。可改变尖角数量、尖角长短比例、整体旋转角度和位置；不要只改变颜色来假装变化。
- 参考页中的星芒并非每页同一种形状：封面 / 结尾更偏轻盈的放射形，角色定义页偏雾蓝的不规则短尖瓣形，路径页则可用更小、更深色的简化闪光形。应根据页面借鉴，不要强行统一成一个 SVG 图标。

## 5. 版式：参考图的五种核心构图

### 5.1 封面 + 右侧目录（参考 01）

- 页面可采用雾蓝主体色与深棕顶部横条。
- 左侧放置大号多行主标题、副标题和一句核心表达。
- 右侧放置 2–4 个编号目录或内容模块。
- 右侧每项包含编号、较粗小标题和一行解释，使用细横线分隔。
- 星芒位于左右栏之间或标题附近，作为视觉锚点。
- 左侧标题必须是主角，右侧目录较小、较克制。

### 5.2 多张错落纸片 / 路径卡片（参考 02）

- 主体常使用杏橙色背景。
- 页面上方安排标题和必要元信息，下半部分放置 3–4 张纸片卡片。
- 卡片使用象牙白、雾蓝、奶油黄、深可可棕等参考色。
- 卡片的宽度、高度、位置与角度可以不同；允许轻微重叠、错位和叠层。
- 不要求卡片边缘完全齐平；要有自然的手作感，但文字阅读顺序必须清楚。
- 纸片的倾斜要有独立变化：例如一张略向左、一张略向右，另一张接近水平；倾角建议控制在约 `-2°` 至 `+2°`，避免所有卡片同角度或整齐平行。
- 原始参考图出现了表情贴纸。只有当主题与语气适合时才可少量使用，不应一概禁止，也不应每页强行添加。
- 不要将其改造成四张完全相同、整齐对齐的 UI 卡片。

### 5.3 左侧大观点 + 右侧解释（参考 04）

这是 Mode1 的重要版式：
- 左侧放置大号核心观点、结论或多行表达。
- 左侧核心文字应处在主体区域的中部附近，不能过于靠上或紧贴页眉。
- 关键短语可使用扁平杏橙色底条强调。
- 右侧放置 2–3 个编号观点，每项包含短标题和简短解释。
- 左侧字号明显大于右侧；右侧是具体解释，不要与左侧争夺主视觉。
- 右侧分隔线使用**连续的实线**，不是虚线、点线或短划线；它只是轻轻提示内容分组，不承担表格边框功能。
- 浅色纸面上优先使用暖灰 `#D8D2C4`，透明度约 30%–45%，线宽约 0.5–0.75 pt；杏橙 / 雾蓝等彩色底上仍以低对比暖灰为主，必要时可用暖象牙白 `#FCFBEA` 并降低至约 20%–30% 不透明度。
- 分隔线长度跟随右侧文字栏宽度，左右端点不要顶到页面边缘；只放在模块之间，模块上下留出呼吸空间。
- 不得使用深棕粗线、纯黑线、虚线、点线或沉重表格网格。若页面需要流程虚线，应只用于真实路径 / 连接关系，不得替代右栏分隔线。
- 左右栏不必等宽，起始高度可以不同。

### 5.4 三行横向对比（参考 06）

- 页面从上到下排列三条横向信息带，参考图的默认色序为雾蓝、奶油黄、杏橙；只有叙事确有需要时才调整顺序。
- 每行左侧放人群 / 情境 / 阶段名称，右侧放具体维度或解释；行内仍保留清楚的左右信息关系。
- 三个直角矩形必须分别处理，不要复制同一个矩形后只替换文字：宽度可相差约 2%–6%，起点可有约 0.08–0.22 in 的水平错位，高度与行间距也可有轻微变化。
- 三行各自使用独立的微倾角，建议落在 `-1.3°` 至 `+1.3°`，并混合正负方向；不要三行全部向同一方向倾斜，也不要每次固定使用相同角度序列。倾斜应像纸片自然放置，而不是明显旋转的斜框。
- 优先让色带矩形与其文字内容作为一个整体轻微旋转；若正文较长或角度影响阅读，则只微倾背景矩形、文字保持水平。不得让文字倾斜到难以阅读。
- 每行的 x / y 起点与宽度要有细微参差，但不能相互碰撞、遮挡或破坏从上到下的阅读顺序。
- 文字密度应足够，每行包含标题和具体说明，不要只剩关键词。
- 不要把三行做成完全等宽、等高、同起点、同角度的标准表格。

### 5.5 结尾观点 + 右侧行动（参考 07）

- 主体可使用杏橙色大面积背景。
- 左侧放一句有记忆点的两行大字，位置舒展。
- 右侧安排 1–2 个观点 / 行动模块，使用细浅横线分隔。
- 星芒可放在左右内容之间，大小和形态与前页不同。
- 结尾应留下原则、行动或邀请，不要机械添加“谢谢”。

## 6. 图片与便签：融入纸张系统

- 图片只有在提供真实证据、展示产品 / 界面或增加必要氛围时才加入。
- 优先使用用户真实产品截图、流程截图、调研材料或可靠素材，不使用无关图库照片填空。
- 图片放入直角照片底板、纸片或便签中；外侧可增加一层轻微错位的纸张衬底。
- 图片上沿可以放一张小型直角标签纸，说明图片内容（如“开发期界面”“时间线截图”）。
- 图片、底板和标签的颜色沿用参考色板，位置可轻微错位。
- 不要使用圆角图片框、厚重阴影或玻璃拟态。
- 必须准确区分原型、开发期界面、已上线功能和已验证结果。

## 7. 信息密度、空间与页脚

- 每页通常包含一个主标题、一个主要视觉结构和 3–5 个有意义的信息单元。
- 不要为了极简只留一句话和大面积空白；也不要为了填满画布堆砌文字。
- 去掉页脚后，必须重新调整主体的垂直位置、间距与整体重心。
- 页面下方允许自然留白，不要默认添加口号、品牌署名、章节说明或装饰性页脚。
- 重要来源、日期、单位、风险和项目状态应放在对应图表 / 文字附近，而不是固定贴在最底部。
- 左侧核心观点应落在舒展的中部区域；右侧说明和卡片文字比核心观点小一档。
- 页面主体不要全部挤在上半部；也不要为了填充底部而加入无意义内容。

## 8. 全局直角限制

所有模式默认使用直角矩形容器：
- 文本框、信息框、便签、卡片、色带、图片底板和容器；
- 不使用圆角矩形、圆角卡片、胶囊标签或圆角图片容器；
- Mode1 顶部文件夹标签可使用参考图中的梯形 / 多边形轮廓，回形针使用细线稿；
- 只有用户明确要求取消该限制时才允许圆角。

## 9. 必须避免的设计问题

- 只提取配色，却替换掉参考图的背景结构、字体与版式；
- 把 Mode1 做成通用商务蓝、科技风或 SaaS 模板；
- 将中文正文改成未经允许的无衬线字体；
- 左侧核心观点过于靠上，右侧分隔线太深太粗；
- 三行信息带和纸片卡片全部齐平，失去俏皮的不规则节奏；
- 每页使用完全相同大小、形状和位置的星星；
- 图片像临时插入的网页截图，没有纸片 / 便签承载；
- 删除底部文字后不重新调整主体布局；
- 为了留白而让信息密度过低；
- 使用圆角矩形、胶囊、厚重阴影、渐变、发光或玻璃拟态；
- 随机图库照片或无关贴纸填空；
- 没有实际渲染和逐页对照就声称通过视觉验收。
