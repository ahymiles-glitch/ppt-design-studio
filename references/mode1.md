# mode1 — 编辑式纸感 / 职业手记

## 1. 设计目标

把演示文稿做成一本经过美术指导的编辑式小册子：兼具个人作品集、职业手记和杂志跨页的气质。

整体观感应当：
- 温暖、克制、有人情味，但有鲜明辨识度；
- 有视觉表现力，却不像常见营销模板；
- 观众几秒内能抓住重点，继续阅读又能获得更多信息；
- 结构专业，但不僵硬、不官腔。

## 2. 视觉设计语言

### A. 配色：暖纸色底 + 有角色的强调色

| 角色 | 名称 | 色值 | 使用方式 |
|---|---|---|---|
| 主背景 | 暖象牙白 | `#FCFBEA` | 页面底色、浅色信息区 |
| 强调色 A | 杏橙色 | `#F7A26B` | 重点页面、章节色带、结论强调 |
| 强调色 B | 雾蓝色 | `#B9D6DC` | 次级信息区、对比行、冷静的说明区 |
| 主文字 | 深可可棕 | `#493729` | 正文、标题、深色顶部色带 |
| 强调色 C | 奶油黄 | `#FBF5A9` | 第三类信息、便签、小面积强调 |
| 强调色 D | 浅桃色 | `#FBD1B8` | 柔和叠层或次级强调 |
| 分隔线 | 暖灰色 | `#D8D2C4` | 细分隔线、弱边界 |

规则：
- 页面主体以暖象牙白或一种大面积纯色为主。
- 单页通常只使用一种主强调色、一种辅助强调色和深可可棕。
- 正文优先使用深可可棕，不使用纯黑制造生硬对比。
- 避免渐变、荧光色、玻璃拟态、厚重阴影和过度圆角的 SaaS 卡片。
- 颜色表达分组或重点，不要纯装饰。
- 数据密集页优先保证对比度和可读性。

### B. 字体：有性格的大标题，安静的正文

- **标题字体**：有编辑感的中文衬线体 / 宋体，优先思源宋体、Noto Serif CJK SC、宋体等。
- **正文字体**：清晰的无衬线体，优先思源黑体、Noto Sans CJK SC、微软雅黑等。

16:9 页面字号参考：
- 封面主标题：34–46 pt；
- 普通页标题：27–36 pt；
- 核心观点：30–42 pt；
- 分区标题 / 卡片标题：16–21 pt；
- 正文：13–18 pt；
- 页码 / 元信息：9–11 pt。

优先通过字号、字重和留白建立层级。正文精简，不要为了塞入长段落而不断缩小字号。衬线字体只用于少量重要表达。主字体通常不超过两种。

### C. 网格与重复页眉

使用稳定的 16:9 画布和充足边距。可以建立以下重复元素：
- 左上角页码，例如 `01 / 07`；
- 页面顶部窄色带或深色横条；
- 从色带向上凸起的一到两个章节标签页；
- 右上角小型回形针线稿；
- 留白处一枚小星芒或四角星。

页眉颜色和当前章节标签可以变化，但页面外边距、页眉基线和页码位置尽量统一。主体网格可以根据内容改变。

### D. 不对称，但必须有隐形网格

可以使用左侧大标题、右侧结构化信息；不同宽度的栏；一个明确视觉锚点；错落纸片卡片；细线分隔列表。避免机械居中、每页相同的等宽卡片、过度旋转和打断阅读顺序的装饰。

### E. 纸感装饰：少量、重复、有理由

可借鉴文件夹标签、便签、回形针线稿、小型星芒、半透明纸片叠层、轻微错位。单页最多使用一到两个装饰母题，优先使用 PowerPoint 原生矢量形状。不要默认使用表情贴纸。

## 3. 信息设计原则

### 一页只解决一个认知任务

每页应回答一个问题：主题是什么、内容如何展开、有哪些路径、岗位解决什么问题、不同起点如何准备、观众最后应记住什么或采取什么行动。

尽可能使用结论式标题。主题标签只说明“本页讲什么”，结论式标题告诉观众“本页应该理解什么”。

### 把文字转化为结构

先识别信息关系：顺序、比较、层级、因果或决策；再选择能够表达这种关系的版式。删除重复表达，但保留限定条件、日期、单位和来源。

常见转化：
- 长段解释 → 一句核心观点 + 三个编号问题；
- 多条路径 → 三到四张有区别的纸片卡片；
- 人群分层 → 横向对比色带；
- 流程 → 有方向的编号阶段；
- 建议 → 大结论 + 两到三个可执行动作。

### 内容密度

建议一个清晰标题、一个主要视觉结构、通常 3–5 个信息单元。若超过五个独立信息单元，考虑拆页或设计有意图的表格，不要用极小字号压缩。

## 4. 页面版式配方

### 配方 01 — 编辑式封面 + 目录
整页使用雾蓝、暖象牙白或其他柔和底色；顶部设置深可可棕横条；左侧放两行左右的大号衬线标题；右侧放 2–4 条编号目录，用细线分隔；加一枚小星芒或回形针。标题必须是主角。

### 配方 02 — 路径 / 类别卡片
使用杏橙色或暖象牙白背景；放置 3–4 张错落纸片卡片；卡片使用象牙白、雾蓝、奶油黄、深可可棕；每张卡片有小编号和简短类别名称。轻微错位即可，文字基线要清晰。

### 配方 03 — 大观点 + 三个问题
左侧放大号多行观点；用扁平杏橙色底条强调关键短语；右侧放三个编号问题，例如“做什么 / 怎么做 / 如何推进”；用细横线分隔。

### 配方 04 — 三类情境对比
纵向堆叠三条横向信息带，每条使用不同浅色；左侧说明人群或情境；右侧放 2–4 个行动或评价维度；栏目标题加粗，解释简短。

### 配方 05 — 结尾观点 + 行动
使用整页杏橙色或暖象牙白；左侧放一句值得记住的两行大字；右侧安排 1–2 个行动模块；重复星芒与标签页，形成首尾呼应。

### 配方 06 — 证据 / 案例页
先用一句话给出结论；主体只放一个证据对象，如图表、标注截图、流程条或精简表格；标注来源、日期和单位；不得用颜色暗示无证据支持的排名或情绪。

## 5. 动效与转场

默认不使用动画，或只使用极克制的淡入与步骤出现。避免弹跳、旋转、3D 翻转和复杂转场。静态页面必须独立成立。

## 6. 必须避免的设计问题

- 泛化商务蓝模板、过度渐变和发光；
- 每页相同的圆角卡片；
- 长段落原样贴入；
- 为保留所有原文而缩小字号；
- 单页过多强调色或混搭图标；
- 随机表情、图库照片填充空白；
- 厚重阴影、粗边框、过度圆角；
- 装饰性页眉挤占正文；
- 页面漂亮却无法在五秒内理解核心信息。

## 7. 中文界面与文字规范

- 面向观众的页面文字默认使用自然、准确的简体中文。
- 页眉、目录、章节标签、卡片栏目名、图表标题、页脚和导航文字，不要无理由保留英文。
- 将 `Overview`、`About`、`Case 01`、`Thank You` 等界面式英文改为自然中文，例如“内容概览”“关于本页”“案例 01”“感谢聆听”。
- 只有专有名词、官方产品名、行业缩写、代码、必要英文原文或用户要求双语时才保留英文。
- 不要逐词硬译，优先使用符合中文表达习惯的短语。AI、SQL、API、ROI 等缩写可按语境保留。

## 8. mode1 验收清单

- [ ] 从封面到结尾具有统一视觉身份。
- [ ] 配色克制，每种颜色都有明确角色。
- [ ] 顶部标签和页码统一，但不会机械重复。
- [ ] 标题具有明确字体和字号层级。
- [ ] 每页只承担一个主要认知任务。
- [ ] 版式根据内容关系变化。
- [ ] 留白有意图，元素对齐有纪律。
- [ ] 装饰母题少量且统一。
- [ ] 不依赖表情贴纸或图库照片制造设计感。
- [ ] 正文在正常演示尺寸下清晰可读。
- [ ] 界面文字使用自然简体中文，英文只在必要时保留。
- [ ] 重要文字和图形仍然可编辑。
- [ ] 已渲染并逐页检查。
