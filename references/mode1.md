# mode1 — 参考图锁定式编辑纸感 / 职业手记

## 0. 最高优先级：参考图是固定模板，不是宽泛灵感

Mode1 的唯一视觉基准，是用户最初提供的那组「产品实习与求职分享」参考页。它的背景系统、色彩组合、字体气质、页眉结构、文字分布和版面节奏必须被持续沿用。

- 除非用户明确要求取消或更换，所有 Mode1 演示文稿都默认使用这套参考模板。
- 后续用户提供的其他风格图片，不自动改变 Mode1；只有用户明确指定时，才用于新模式或本次任务的局部调整。
- 用户最新明确指令优先于本文件。
- 不要把“参考图风格”理解成只保留几种颜色、再自由设计一套新模板。应尽可能复现参考图的整体页面神态与构图方式。
- 背景不是每页必须使用同一种纯色，而是沿用参考图已有的固定背景系统和页面色彩搭配：奶油白纸张边缘、深棕顶部横带、凸起标签页，以及雾蓝、杏橙、浅黄、奶油白等参考页中出现的纯色主体区域。
- 不得擅自改成渐变背景、玻璃拟态、科技蓝、黑金商务模板或其他与参考图无关的视觉体系。

## 1. 设计目标

把演示文稿做成一本轻松、有趣、带有纸张触感的编辑式小册子：像认真设计过的职业手记、作品集或杂志跨页，而不是僵硬的企业模板。

应当同时做到：
- 第一眼有鲜明的整体风格，继续阅读时层次清楚；
- 俏皮、自然、有一点手作感，但不幼稚；
- 结构清晰，却不追求每个元素绝对对称；
- 文字有主次，信息密度张弛有度；
- 留白充足，但不能为了极简把页面做得空洞。

## 2. 背景与色彩：严格沿用参考图

### 2.1 固定背景结构

优先沿用参考页的组合方式：
- 奶油白或暖象牙白的外围纸张底色；
- 顶部深可可棕横条或参考图对应的窄色带；
- 从色带边缘凸起的文件夹标签页；
- 参考图中使用的纯色内容区域；
- 右上角细线回形针；
- 左上角页码与右侧章节标签。

背景与顶部结构应稳定重复，主体颜色可在参考图已有的搭配之间切换。切换时必须有参考页依据，不要自行发明新配色组合。

### 2.2 固定参考色板

以下为从参考图整理的近似数字色值，用于保持一致，不代表原始设计文件的精确取色：

| 角色 | 色值 | 用法 |
|---|---|---|
| 奶油白 / 纸张底色 | `#FCFBEA` | 外围纸张、浅色内容页 |
| 杏橙色 | `#F7A26B` | 大面积主体色、章节色带、强调条 |
| 雾蓝色 | `#B9D6DC` | 主体色、信息带、便签 |
| 深可可棕 | `#493729` | 顶部横带、标题和正文 |
| 奶油黄 | `#FBF5A9` | 便签、重点短语和小面积强调 |
| 浅桃色 | `#FBD1B8` | 次级纸片或柔和叠层 |
| 暖灰分隔线 | `#D8D2C4` | 右栏分隔线、弱边界 |

规则：
- 每页以一种主体纯色为主，辅助色只承担分组或强调功能。
- 同一页不要把所有色板颜色平均铺开。
- 文字优先使用深可可棕；避免纯黑造成生硬感。
- 颜色必须保持参考图的低饱和、温暖关系。
- 不使用渐变、荧光色、金属质感、厚重阴影或高对比发光效果。

## 3. 字体：锁定参考图，不得擅自替换

字体是 Mode1 的固定设计资产，不是每次制作时自由选择的变量。

- 始终沿用最初参考图中对应的中文字体气质、英文字体气质和数字样式。
- 中文标题沿用参考图中的宋体系 / 衬线编辑感；正文与辅助信息沿用参考图中对应的清晰、克制的文字风格。
- 英文和数字沿用参考图中的衬线或斜体表现，不要随意改成系统默认无衬线字体。
- 整份 PPT 保持同一套字体组合、字形气质和字重逻辑；不要封面一套、正文另一套。
- 禁止未经允许擅自替换成微软雅黑、思源黑体、Aptos、Arial 或其他不同风格字体。
- 如果用户提供了原始 PPTX、字体文件或明确字体名称，应直接沿用准确字体。
- 如果目前只有截图、无法可靠识别字体的确切名称，不得编造字体名称；应按截图字形做最接近的视觉匹配。若确切字体一致性无法保证，先向用户说明并确认，不要静默换风格。
- 不要为了兼容性擅自改变字体。字体缺失、嵌入或跨设备替换风险应在交付前检查并说明。

字号层级参考（可按实际画布与文字长度微调）：
- 封面主标题：34–46 pt；
- 普通页核心标题：28–40 pt；
- 右侧分区标题：16–21 pt；
- 正文与辅助说明：12–16 pt；
- 页码和元信息：9–11 pt。

字号层级要明显：左侧核心观点大，右侧解释文字略小；但右侧不能缩到难以阅读。

## 4. 页眉、装饰与固定识别元素

持续沿用参考图的页面识别系统：
- 左上角小页码；
- 顶部深棕或参考图对应色带；
- 一到两个凸起的文件夹标签页；
- 右上角细线回形针；
- 页面空白处的一枚小星芒。

### 星芒必须有自然变化

- 每页星星的大小不必相同。
- 星形可以在四角星、五角星、八角星或参考图相近的星芒形态之间变化。
- 旋转角度可以略有差异。
- 不要把同一枚星星复制到每页同一个位置，也不要机械重复完全相同的形状。
- 星芒是视觉节奏，不是填空装饰；每页通常一枚即可，必要时最多两枚。

## 5. 版式：复现参考图的文字分布方式

不要将所有页面统一成同一种左右栏，也不要把所有内容都装进卡片。根据参考图中的具体构图选择版式。

### 5.1 左侧核心观点 + 右侧具体解释

这是 Mode1 的核心版式之一：
- 左侧放置较大的标题、结论或最重要的一句话；
- 左侧核心内容应落在参考图对应的中部区域，不要紧贴页眉，也不要过于靠上；
- 左侧可以由标题、短结论和一条扁平强调条组成；
- 右侧放置更具体的解释、编号观点或行动建议；
- 右侧文字字号明显小于左侧核心观点，但仍需清晰易读；
- 右侧各观点之间使用细、浅、低对比度的暖灰横线分隔；
- 横线只帮助分组，不要变成明显的表格网格或粗边框；
- 左右栏宽度可以不相等，按参考图的视觉重心调整。

典型分布：
- 左侧：大标题 / 核心结论 / 关键短语；
- 右侧：编号 / 小标题 / 具体解释；
- 右侧说明不要挤成一团，段落之间保持呼吸空间。

### 5.2 从上到下三行并列的信息带

参考图中的三行对比页是重要版式，不要改成三个完全规整的卡片：
- 页面从上到下排列三条横向矩形信息带；
- 每行使用参考图中的不同纯色角色；
- 三条矩形可以有轻微上下错位、宽度差异或小角度倾斜；
- 不要求左右边缘、起始位置和终止位置完全齐平；
- 每一行内部的信息仍应有清楚的列关系：左侧说明情境或人群，右侧安排具体维度；
- 轻微参差是设计语言，不得影响文字对齐、阅读顺序或信息比较；
- 保持中等信息密度：每行需要有足够的标题和解释，不要只剩一个词或一句空泛口号。

### 5.3 便签式文本框

便签是可选的文本承载方式，应作为 Mode1 的重要版式工具：
- 使用直角矩形便签，不使用圆角卡片；
- 可使用奶油白、雾蓝、奶油黄、深棕等参考色；
- 便签之间允许轻微错位、不同高度、轻微倾斜；
- 便签可承载标题、短说明、编号，也可以嵌入小图；
- 不要所有便签做成完全相同的尺寸、角度和位置；
- 文字要与便签颜色保持足够对比；
- 便签不等于 SaaS 卡片，不加厚重阴影、圆角和复杂边框。

### 5.4 证据与图片页

- 只有当图片能提供真实证据、展示产品或增加必要氛围时才加入。
- 图片可以放在便签内、纸张底板上，或作为一张轻微错位的纸质照片。
- 图片框、底板和标签全部采用直角矩形；可通过轻微错位和纸张叠层增加趣味。
- 图片与页面的色彩、纸感和留白必须融为一体，不能像临时插入的网页截图。
- 优先使用用户真实产品截图、流程截图或可靠素材；不使用无关图库图片填空。
- 截图中的开发状态、示意状态和已验证功能必须准确区分，不得把原型描述为已上线。

## 6. 信息密度与留白：张弛有度，不要过度极简

Mode1 不追求“越空越高级”，也不追求把每个空白都填满。

- 每页通常保留一个明确主标题、一个主要构图和 3–5 个有意义的信息单元。
- 左侧核心观点应足够醒目；右侧解释、便签文字和三行对比的说明要比主标题小一档。
- 去掉底部页脚或总结语后，应重新分配主体内容的位置和间距，不能只删除文字却保持原来的拥挤构图。
- 页面下方允许自然留白，不要为了填满画布添加无意义的文字或装饰。
- 不要把主体内容全部挤在页面上半部；根据参考图把核心观点放在更舒展的中部位置。
- 正文可以精简，但不得删掉理解主题所必需的事实、限定条件、数据单位或来源。
- 不得为了追求留白而把内容削减到过于空洞；也不得为了填满页面而堆砌文字。

## 7. 直角限制：所有 Mode 通用的硬性规则

此规则不仅适用于 Mode1，而是 PPT 设计工坊所有模式的全局限制：

- 文本框、信息框、便签、卡片、色带、图片底板和容器默认全部使用直角矩形。
- 禁止圆角矩形、胶囊形标签、圆角卡片和圆角图片容器。
- 如需强调，可使用直角色块、细线、纸片叠放或轻微倾斜，不得用圆角替代。
- 只有用户明确要求取消这一限制或明确指定圆角设计时，才允许使用圆角。

## 8. 页脚规则

- 不要默认在每页最下方放置一行口号、品牌署名、章节说明或装饰性页脚。
- 页面底部可以保留一段自然空白。
- 如果确实需要来源、版权或重要限定条件，应将其放在相关内容附近，以低调但可读的方式呈现，不要为了统一页脚而机械放在最底部。

## 9. 动效与转场

默认不使用动画，或只使用极克制的淡入与步骤出现。避免弹跳、旋转、3D 翻转和复杂转场。即使关闭动画，静态页面也必须成立。

## 10. 必须避免的设计问题

- 擅自更换参考图的背景系统、字体组合或色彩搭配；
- 将 Mode1 简化成只有几种粉彩色的通用商务模板；
- 每页都使用完全相同的左右栏、同尺寸卡片或同一颗星星；
- 三行信息带被排成僵硬、完全齐平的标准表格；
- 所有主体文字都挤在页面上方；
- 右侧分隔线太深、太粗，抢走文字注意力；
- 删除底部文字后不重新调整页面布局；
- 为了极简而让信息密度过低；
- 使用圆角矩形、胶囊、圆角卡片；
- 使用渐变、发光、玻璃拟态、厚重阴影；
- 用随机图库照片、表情贴纸填充空白；
- 字体缺失时未经允许换成另一套字体。

## 11. mode1 验收清单

- [ ] 背景结构与色彩搭配仍属于最初参考图的固定模板。
- [ ] 未经允许没有替换参考图字体或字体风格。
- [ ] 页眉、标签页、页码和回形针保持统一。
- [ ] 星芒在大小、形状或角度上有自然变化，而不是机械复制。
- [ ] 左右结构中左侧核心观点位于舒展的中部区域，右侧文字略小。
- [ ] 右侧观点之间的分隔线足够浅、足够细。
- [ ] 三行并列信息带略有参差，但内部信息清楚。
- [ ] 便签可作为文本框选择，并有轻微错位与纸感。
- [ ] 图片被整合进纸片或便签体系，不显得突兀。
- [ ] 主体内容有足够空间，底部可自然留白。
- [ ] 信息密度张弛有度，不空洞也不拥挤。
- [ ] 全部文本框、卡片、图片容器和色带均为直角。
- [ ] 没有机械添加底部页脚。
- [ ] 已渲染并逐页检查字体、溢出、碰撞和整体节奏。
- [ ] 所有关键事实、数据和项目状态均有用户资料支持。
