- Songti + Georgia typography (verified from the PowerPoint font declarations).

- Large left-side statements paired with smaller right-side explanations.
- Starbursts, sticky-note labels, layered rectangular photo frames, and screenshot evidence.
- No decorative footer line; caveats and validation notes sit next to the relevant content.
- Editable native text and vector shapes; interface screenshots remain image objects.
